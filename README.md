# SRMS

A simple **C language** project that manages student records using **file handling** and a **role-based login system**.

## Features
- Login system using `credentials.txt`
- Roles: **Admin**, **Staff**, **Guest**
- Add, Display, Search, Update, Delete students
- Search by Roll or Name
- Show statistics (highest, lowest, average marks)
- Change password (for all users)
- Automatically creates `students.txt`
